# Local profiles

`illustrative_canonical-v1.json` describes the only executable profile. It is synthetic and provides no Wiz-specific field or relationship mapping. The runtime rejects any other export profile ID.

The impact-profile schema is an interface for later user-approved documents and criteria, not an installed rubric. An ATT&CK catalog and Attack Flow bundle are likewise absent. Do not add profile files by copying examples and assume that doing so authorizes ratings or technique IDs; loader and validation rules must be implemented and reviewed with the supplied materials.
