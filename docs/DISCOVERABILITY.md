See [GitHub's topic guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics).

Topics are hosted repository metadata and must be updated separately from Git
commits. Version tags remain reserved for actual releases. Keep the README and
[capability catalog](CAPABILITIES.md) aligned with the About description.
