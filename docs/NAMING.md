# COPS naming conventions

| Surface | Name |
| --- | --- |
| Project, first mention | COPS (Copilot Operations Plugins for Security) |
| Subsequent project mentions | COPS |
| First plugin display name | COPS Security Logging Advisor |
| Repository slug | `copilot-operation-plugin-for-security` |
| Existing package, agent, command and plugin ID | `security-logging-advisor` |
| Marketplace ID | `cops-security-marketplace` |

Use the expanded project name in introductions and COPS in headings and everyday
prose. Describe COPS as a cybersecurity project for plugins, agents, and skills.
Prefix product display names with COPS and give each add-on a clear security
purpose. Preserve machine identifiers and
paths until an explicit compatibility migration is planned; branding does not
change installation identities or JSON schemas. Retain third-party project names
such as PARK in attribution and upstream references.

The [COPS logo](assets/cops-logo.png) is an original AI-generated shield and pilot
visor illustration. It is project artwork, not a GitHub, Microsoft, or law
enforcement mark. Its presence does not imply endorsement by those organizations.
