# Engagement retest and closure

An offline retest compares a validated baseline assessment with a later validated assessment for the same engagement. It never executes an assessment or closes an issue. The comparison identifies each baseline finding and exact asset, links an explicit retest observation to assessed evidence, and records closure gates for ownership, cleanup, authorization, and evidence gaps.

A supplied `absent` observation is `candidate_fixed` only when a later laboratory or live retest has assessed coverage of the same scenario and exact asset and the observation references record IDs absent from all baseline coverage and findings. A supplied `present` observation is `candidate_still_vulnerable` only when the retest report also contains an assessed finding for that scenario and asset with overlapping new evidence. Record-ID novelty does not independently establish observation time. Inaccessible, blocked, unassessed, changed-identity, and unsupported observations cannot be promoted to a fix. A missing observation is `not_assessed`.

The workflow validates the report contracts, engagement identity, chronological order, unique finding/asset checks, bounded cleanup receipts, and receipt digests. Input and saved report documents are bounded at 4 MiB. Baseline affected assets must be unique after canonical normalization within each finding, and one input can expand to no more than 10,000 finding and asset results. Cleanup v2 unresolved effects retain their optional quarantine target in the review report. A completed or not-required receipt is required for each named plan before closure review. An owner acknowledgment is a supplied assertion requiring independent review. Every live retest needs independent authority and cleanup run binding, even if plan IDs match; a changed plan additionally needs fresh authorization unless its exact actions and budget are already covered by a valid bound approval. The output always blocks closure. Recomputing a saved report against supplied input detects report tampering but does not authenticate either source, observation time, actual cleanup, or authority.
